# Лог дня

Инструмент записи дня на неделю 19–25.10.2026 и дальше: подъём, главный результат, четыре отметки, закрытие дня, итоги недели. Чистые HTML, CSS и JS, без сборки, сети, аккаунтов и аналитики.

## Запуск

```bash
cd log-app
python3 -m http.server 8000
```

Открыть `http://localhost:8000`. После первой загрузки приложение работает офлайн (service worker `sw.js`).

Через `file://` открывать не стоит: браузер может не сохранять данные между запусками и не включит офлайн-режим.

### На телефоне (Андроид)

**Опубликовано:** https://limoncheloes.github.io/daylog/ — открыть в Chrome на телефоне, меню ⋮ → «Добавить на главный экран». Обновление: изменить файлы, `git commit` и `git push`. GitHub Pages пересоберёт сайт примерно за минуту, а телефон подхватит новую версию со второго открытия (сначала отдаётся кэш, свежие файлы докачиваются в фоне).

Service worker и установка на «Домой» работают только на `https://` или `localhost`. Другие варианты:

- **Статический хостинг** (GitHub Pages, Netlify, Cloudflare Pages): залить содержимое `log-app/`, открыть в Chrome, меню → «Добавить на главный экран».
- **Termux на самом телефоне**: `pkg install python`, скопировать `log-app/`, запустить `python -m http.server 8000` и открыть `http://localhost:8000`.
- По Wi-Fi с компьютера (`http://192.168.x.x:8000`) запись работает, но офлайн-режима и установки не будет: это не защищённый адрес.

Данные хранятся отдельно для каждого адреса. Если сменить адрес, сначала сделай экспорт JSON на старом и импорт на новом.

## Где лежат данные

- `localStorage` браузера, ключ `daylog.v1`: настройки и все дни. Сохраняется после каждого изменения.
- `daylog.meta`: дата последней резервной копии и служебные отметки для режима папки.
- Если сохранённые данные не читаются, приложение не затирает их, а откладывает в `daylog.v1.broken`.

## Резервная копия

- **Экспорт JSON**: «Настройки → Экспорт JSON» или ссылка «Резервная копия» на экране «Сегодня». Если копии не было больше недели, сверху появится баннер.
- **Импорт**: «Настройки → Импорт JSON или .md». Дни объединяются по дате, побеждает запись с более новым `updated_at`, повторный импорт ничего не дублирует. Настройки из JSON заменяют текущие. Импорт `.md` принимает файлы дня в формате 1.5 (несколько сразу); за `updated_at` берётся время изменения файла.
- **CSV**: все строки лога одной таблицей (UTF-8 с BOM, открывается в Excel).
- **Markdown дня**: «Закрыть день → Скачать .md / Копировать .md».

Safari может стереть данные сайта, который не открывали 7 дней, если он не добавлен на «Домой». Экспорт раз в неделю спасает от этого и от потери телефона.

## Как пользоваться

0. **Списки.** По умолчанию списки занятий и триггеров пустые. Заведи их в «Настройках» (поле «Новое занятие», Enter — следующий) или прямо в форме отметки кнопкой «+ новое». Там же назначь две роли:
   - **«Спрашивать триггер у занятия»** — например, «Ленты не по плану». Только у этого занятия форма спрашивает триггер, и только оно считается в разделе «Триггеры».
   - **«Занятие с целью на неделю»** — например, ваш главный проект. Его минуты идут в табло недели и в `greenhouse_min` файла дня. Если роль не назначена, `greenhouse_min: null`, а строки цели в табло нет.

   В редакторе название правится на месте (ключ при этом не меняется, старые записи не ломаются), ↑ поднимает пункт выше, ✕ удаляет. Пункт, который уже есть в записях, не удаляется, а скрывается: из формы он пропадает, а старые строки сохраняют подпись. Вернуть его можно там же.
1. **Утро.** «Сегодня»: подъём («Сейчас») и главный результат.
2. **Отметка** (11:30, ~14:10, 17:30, 21:45): «Отметка» → занятие → энергия → вовлечённость → «Сохранить». «От» подставлен концом прошлой строки (или подъёмом), «До» — текущим временем. Чтобы разбить период: поставь в «До» время конца первого занятия и нажми «Сохранить и ещё»; следующая строка начнётся оттуда.
3. **Правка.** Нажми на строку: можно поменять всё, разделить в указанное время или удалить. Между строками видны пропуски от 10 минут; кнопка «заполнить» открывает форму на это время.
4. **Вечер.** «Закрыть день»: экранное время (`340`, `5:40`, `5ч40`), да/нет (повторное нажатие снимает ответ), дневник по строке на пункт. «Скопировать для /day» даёт строку для ассистента.
5. **Неделя.** Табло, часы, занятия, триггеры. «Скопировать итоги недели» — Markdown для воскресного обзора.

Стрелки ‹ › у даты открывают прошлые дни. Строки там по умолчанию помечены «по памяти».

## Режим папки (Chrome, Edge на компьютере)

«Настройки → Подключить папку journal». Приложение пишет каждый изменённый день в `ГГГГ-ММ-ДД.md` (формат 1.5) и читает файлы, которые поменяли снаружи. В существующем файле обновляются только ключи front matter из формата, заголовок и шесть своих разделов. Чужие ключи и разделы (например, «План на завтра») остаются на месте. Демо-дни в папку не пишутся.

Браузер может сбросить разрешение между сессиями. Тогда на «Сегодня» появится «Разрешить». В Safari, Firefox и Chrome на Андроиде этого режима нет, остаётся экспорт.

Если внешняя программа перезапишет файл дня целиком без раздела «Лог», при синхронизации этот день в приложении заменится версией из файла (правило «новее — побеждает»).

## APK-обёртка

Если на странице есть объект `window.Android` (его даёт своя APK-обёртка с WebView), приложение работает через него: записи пишутся сразу в файл приложения, а не в `localStorage`; экспорт сохраняется в «Загрузки»; копирование идёт через системный буфер; кнопка «Назад» ведёт на «Сегодня»; service worker не регистрируется. В браузере всё работает как раньше.

## Проверка без ожидания ночи

`http://localhost:8000/?now=2026-10-20T02:30` подменяет часы приложения. Запись в 02:30 попадёт в 19.10, а с `?now=2026-10-20T04:05` — уже в 20.10.

## Допущения

- **Хранилище** — localStorage, а не IndexedDB: данных мало (год ≈ 1 МБ), код проще. IndexedDB используется только для доступа к папке.
- **Отметка «сделана»**, когда лог дошёл до её времени (конец последней строки не раньше чем за 15 минут до отметки). **«Пора»** — за 10 минут до времени отметки и позже. Номер отметки у строки (`checkin`) — первая отметка, до которой строка закончилась (с запасом 30 минут на опоздание). У строк после последней отметки — `null`.
- **Сутки** заканчиваются в 04:00: строки 00:00–03:59 идут после 23:59 того же логического дня, строка через полночь считается правильно.
- **Средние** энергии и вовлечённости по часам и по занятиям взвешены по минутам. Лучшие и худшие часы — по среднему из энергии и вовлечённости, при равенстве выше час с бо́льшим числом минут.
- **«Что даёт энергию»** — до трёх занятий со средней энергией > 0, **«Что забирает»** — до трёх с энергией < 0.
- **Триггеры** считаются по строкам занятия с ролью «спрашивать триггер». Строка без триггера — «не указан». Час — по началу строки. У других занятий триггер не сохраняется.
- **Лимит экрана** берётся по лестнице на дату дня. До первой ступени действует первая ступень (6:00).
- **Обязательны** время, занятие, энергия и вовлечённость. Триггер — мягкая подсказка, пересечение строк — предупреждение.
- **Списки и роли** хранятся в настройках: `activities` и `triggers` — `[{key, label, hidden?}]`, роли — `goal_activity` и `trigger_activity` (ключи занятий). Ключ создаётся из названия транслитом (`Главный проект` → `glavnyy_proekt`) и дальше не меняется. В модели брифа ролей не было, там они были зашиты в ключи `greenhouse` и `phone_off`. Данные первой версии с такими ключами получают роли автоматически.
- **Названия** в списке не повторяются (без учёта регистра): по названию файл дня разбирается обратно.
- **Включение отметок** хранится в `settings.checkins_on` рядом с `checkins` (в модели брифа этого поля не было).
- **Демо-неделя** пишется в прошлую неделю, только в пустые дни, с флагом `demo: true` — так она не задевает настоящие данные. Свои пункты она добавляет в списки с пометкой `demo` (если пункта с таким названием ещё нет) и назначает роли, только если они не заданы. «Убрать демо-дни» удаляет демо-дни, демо-пункты (кроме переименованных и использованных в настоящих записях) и снимает роли, которые на них указывали.
- **Тексты в Markdown** приводятся к одной строке, а « · » внутри заметок заменяется на «, », чтобы не сломать разбор строки лога.
- **Цель недели** по занятию (по умолчанию 7:30) задаётся в настройках.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | каркас страницы |
| `app.js` | вся логика: данные, расчёты, Markdown, экраны, действия, режим папки |
| `styles.css` | вид, светлая и тёмная тема |
| `sw.js` | офлайн-кэш (при изменении файлов подними `CACHE`) |
| `manifest.webmanifest`, `icon*.png`, `icon.svg` | установка как приложение |
